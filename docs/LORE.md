## 二、十技 × 原著设定 深度对齐表

### 1. 炁体源流 `qiti-yuanliu` — context-guard

**原著核心**：炁是异人异能的本质能量流。炁体源流能诊断炁的运行是否正常、是否有漏气、是否有外力干扰。

| 原著概念 | 项目映射 | 对齐度 |
|---------|---------|--------|
| **炁**（生命能量流） | 对话上下文（context）——Agent 的"气脉" | ★★★★★ |
| **炁体诊断** | `entropy_scanner.scan()` — 多维健康指标计算 | ★★★★★ |
| **炁漏**（能量流失）| 上下文熵增（entropy↑）、目标漂移 | ★★★★★ |
| **炁体污浊** | 矛盾冲突、冗余重复 | ★★★★☆ |
| **源流**（本源追溯）| DNA快照 — 追溯最初N轮决策指纹 | ★★★★★ |
| **稳态**（炁归位）| `repair_handoff` 稳态修复契约 | ★★★★☆ |
| **炁感知** | `alignment` 目标对齐度检测 | ★★★★☆ |

**强化建议**：
- 当前 `entropy` 直接使用信息熵概念，可在文档中补充隐喻：**"炁熵"**指上下文能量的无序度，数值越高说明炁场越混乱。
- `repair_handoff` 可命名为"**炁归契约**"——当炁体检测到污浊无法自愈时，移交给大罗洞观进行深度追踪。
- `dna_snapshot` = **"炁印"**：一段对话中决策的能量指纹，类似异人识别其本源炁体特征。

| **符胆**（符力核心）| 任务意图（task description） | ★★★★☆ |
| **通天**（贯通上下）| 拓扑排序——打通任务上下游依赖 | ★★★★☆ |

**6种符箓类型原著对齐**：

| 符箓类型 | 技术含义 | 原著隐喻 |
|---------|---------|---------|
| `retrieval` | 信息检索 | **查阅符** — 问道符，问天地问鬼神 |

**强化建议**：
- `quick-cast` 编排模式 = "**速符**"（临阵急画，力弱但快）

### 6. 六库仙贼 `liuku-xianzei` — knowledge-digest

**原著核心**：六库仙贼指一种能随时"窃取"并储存信息于六座内在信息库的奇技。"仙贼"含义：以窃取为手段，但取到的都是有价值的东西，最终化为自身的宝藏。六库即六个分类仓库。

| 原著概念 | 项目映射 | 对齐度 |
|---------|---------|--------|
| **六库**（六类仓库）| 六种信息分类（技术方案/行业数据/法规/理论/社区/默认） | ★★★★☆ |
| **仙贼窃取** | 从输入信息中"萃取"知识精华 | ★★★★★ |
| **消化转化** | `digest()` — 将原始信息转化为结构化知识单元 | ★★★★★ |
| **保鲜期** | 原著没有明确对应，为技术创新：知识的时效性管理 | ★★★☆☆ |
| **信息可信度 S/A/B/C** | "窃取"的信息有真有假，需分级辨别 | ★★★★☆ |
| **反刍调度**（复习计划）| 原著无对应，技术创新：艾宾浩斯遗忘曲线 | ★★★☆☆ |

**六库对齐**：

| 库名 | 保鲜期 | 隐喻 |
|------|--------|------|
| **法律法规库** | 7天 | 律法随时会变，朝令夕改需随时跟新令 |
| **技术方案库** | 90天 | 技术迭代快，三月一小变 |
| **行业数据库** | 180天 | 半年一轮回，数据老化但仍有参考价值 |
| **社区经验库** | 90天 | 江湖消息，三月过后多半失效 |
| **基础理论库** | 1095天（3年） | 大道不易，基础规律万古长存 |

**强化建议**：
- `inheritance_queue`（可继承知识）= **"入库"**：经炼化后品质合格的知识可入库长存
- `quarantine_queue`（隔离队列）= **"待验"**：疑似假货/毒物，放在隔离室等待验明正身
- `contamination_risk`（污染风险）= **"毒信"**：六库仙贼取到的可能是带毒的假消息，需防止毒信污染本库
